INSTALAÇÃO / ATUALIZAÇÃO

1. No Supabase, abra SQL Editor e execute supabase-medications.sql uma vez.
2. Envie todos os arquivos desta pasta para a mesma pasta publicada pelo GitHub Pages.
3. Preserve exatamente os nomes dos arquivos, sem sufixos como “(2)” ou “(8)”.
4. Aguarde a publicação do GitHub Pages e pressione Ctrl+F5 no navegador.

O novo módulo usa a mesma conta e o mesmo projeto Supabase das outras áreas.
